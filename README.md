# OTT Content Performance Analytics

# Project Overview:

-> This project analyzes OTT content performance across platforms, genres, content types, ratings, popularity, engagement, and release trends using Power BI.
-> The goal is to identify content patterns and generate data-driven insights that can support OTT content strategy and decision-making.

## Business Objectives:

- Analyze the OTT content library across platforms
- Compare content distribution by platform and type
- Identify high-performing genres
- Compare average ratings across platforms and genres
- Analyze popularity and engagement patterns
- Understand content release trends over time
- Generate business recommendations from the analysis

# Tools & Technologies:

- Power BI
- Power Query
- DAX
- Microsoft Excel

# Dataset:

* The dataset contains 2,500 OTT content records with information including:

- Content title
- Content type
- Genre
- Platform
- Country
- Language
- Release year
- Duration
- Rating
- Votes
- Weighted rating
- Engagement score
- Popularity score
- Trending score
